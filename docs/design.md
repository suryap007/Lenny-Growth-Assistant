# UI/UX Design

## Layout
- **Left Sidebar**: Chat session history.
- **Top Bar**: New Chat button, LLM Provider toggle.
- **Center**: Chat messages (User & Assistant).
- **Right Panel (Collapsible)**: Artifact Viewer.

## Aesthetics
- ChatGPT-like simplicity.
- Plain CSS without UI frameworks.
- Light theme with clean spacing and subtle hover effects.
- Artifacts sandboxed in an iframe for secure HTML/CSS rendering.
