# Lenny Growth Assistant PRD

## Overview
A ChatGPT-like conversational web application grounded on Lenny's Podcast transcripts.

## Features
1. **RAG Q&A**: Answers questions strictly from transcripts.
2. **Ship30for30 Essays**: Generates structured essays based on podcast insights.
3. **Artifact Generation**: Renders Markdown and HTML/CSS artifacts side-by-side with chat.
4. **Session Memory**: Persists multi-turn conversations.
5. **Provider Switch**: Toggles between cloud (OpenAI) and local (Ollama) LLMs.

## User Stories
- As a user, I want to ask growth questions and get answers grounded in Lenny's podcast.
- As a creator, I want to generate Ship30for30-style essays from specific episodes.
- As a developer, I want to request UI components and see them rendered instantly.
- As a user, I want to view my past chat sessions.
